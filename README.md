TETROBITS is a 2D puzzle game where you stack and clear falling pieces on a board to score points. Clearing pieces containing special BIT-blocks yields BITS, a currency spent on upgrades and unlocks.

One of the unlocks is Frenzy Mode, where the pace picks up and a timer starts ticking. Clear lines to keep it going and survive, or run out of time.

Built with React, Vite, Tailwind CSS, and the Canvas API.

## Features

- DOM for the UI, Canvas API for the board
- Progression system with XP and levels
- BITS, an in-game currency from BIT-blocks
- Frenzy Mode, a faster timed variant
- Upgrades that boost overall progression
- Stats and settings saved locally

## Installation

1. Ensure you have Node.js and npm installed
2. Clone this repository

```bash
git clone https://github.com/soringavra/tetrobits.git
cd tetrobits
```

3. Install dependencies

```bash
npm install
```

4. Start the dev server

```bash
npm run dev
```
